# and-games-studio.github.io

The And Games studio page, at the root of `https://and-games-studio.github.io/`: the list of the studio's games, each linking to its own site in its own repository (`And-Games-Studio/<game>`, such as [Split It!](https://and-games-studio.github.io/splitit/) and [ReVive](https://and-games-studio.github.io/revive/)), and `app-ads.txt`, the ad sellers authorised for all the studio's apps, which Google AdMob reads at the root of the developer website listed on the stores. Plain and neutral on purpose: each game's site has the game's look.
