# and-games-studio.github.io

The And Games studio page, at the root of `https://and-games-studio.github.io/`: the list of the studio's games, each linking to its own site (such as [Split It!](https://and-games-studio.github.io/splitit/), in its own repository, or ReVive's in `revive/` here: its home page and privacy policy, in the game's colours), and `app-ads.txt`, the ad sellers authorised for all the studio's apps, which Google AdMob reads at the root of the developer website listed on the stores. Plain and neutral on purpose: each game's site has the game's look.
